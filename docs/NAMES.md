# Names used in Laminar

Check this file and section 8 of `.github/LONGLIGHT-STUDIO.md` before adding
any name. Add every new name here.

**Do not use:** Kestrel, Kessel, Kessler, Harbourline, Hollis, Lantern,
Halyard, Sable, Ember, Kite, Harrow, Corvid, Tidewater, Northwind, Nimbus,
Heron, Courier, Ledger, "Prairie", any new country starting with V, or
"Flutter" as a proper name (it's a saved game idea).

**Hull Down overlap.** Hull Down also uses Tarnovia, with its own canon
(korona money, no Mostograd). Kelbo chose rubles and Mostograd for Laminar
(15 November 2026), so the two are separate takes on the country. To keep them
from blurring, don't reuse Hull Down's names: Kamen Pact, Radan Union,
Northern Accord, Pelnik, Dravec, Sokolin, Pavel Sedlar, Warden, Palisade, or
its export countries (Dahrat, Ilandu, Tolmar, Ekunde, Orvenn, Zamuri, Qasirah).

**Mostograd** belongs to Lombard. Any Mostograd place or institution must not
contradict Lombard's `docs/01-GDD.md` (Setting and Brands).
